# Conformance corpus

Generated by `go run ./cmd/cover`. Do not edit by hand — regenerate.

195 cases covering 214 behaviours of the machine.

## How to run these

Each case is three files:

| file | contents |
|---|---|
| `NNN-….ndjson` | external events only, in the recorded-trace wire format |
| `NNN-….driven.ndjson` | the same run with its internal steps in place |
| `NNN-….json` | the behaviour witnessed, and the expected outbox |

**Driven tier** — replay every row, including the `tau.*` rows, firing the
named internal step at the named instant. Every response is then forced:
assert equality on all of them.

**Observational tier** — replay the `.ndjson` only, letting the server run
its own internal loop. Promise-facing responses are still forced; task-facing
ones are not, because the stage of the wake pipeline is visible at the task
interface by design. Assert those at quiescence.

Both tiers need a controllable clock: `now` is synthetic and the deadlines
in the requests are drawn against it.

Of 195 cases, 190 run in both tiers and 5 need a driveable internal
loop. The latter have no `.ndjson`: an internal step that fires with its
obligation already discharged is a silent no-op, so their observational
projection is empty and no request/response capture can witness them.
